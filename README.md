# Repwise AI

A full-stack mobile workout tracking app built with **React Native (Expo)** and a **Python Flask** backend, powered by **Supabase** for authentication and data storage.

---

## Features

- **Workout Logging** — Log workouts by date, with support for multiple exercises and sets (weight × reps). Drag to reorder exercises before saving.
- **Calendar View** — Visual calendar showing days you've worked out, with tap-to-view past workout details.
- **Stats Dashboard** — Three stat views:
  - *Recent* — Longest streak and workout type breakdown for the last 30 days
  - *Overall* — All-time streaks, workout percentage, best month, and distribution chart
  - *Weight* — Per-exercise analysis including estimated 1-rep max, total volume, and progression charts
- **AI Tips** — Personalised coaching tips generated by Claude, based on your last 60 days of training data
- **AI Chatbot Coach** — Agentic conversational coach that can fetch and analyze your workout data to answer questions
- **Dark / Light Mode** — Full theme support across the app

## Getting Started

### Prerequisites
- Node.js 20+
- Python 3.10+
- Expo CLI
- A Supabase project

### 1. Clone the repo

```bash
git clone <repo-url>
cd workout-app
```

### 2. Server setup

```bash
cd server
pip install -r requirements.txt
```

Create a `.env` file in `/server`:

```env
SUPABASE_URL=your_supabase_url
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
ANTHROPIC_API_KEY=your_anthropic_key
MY_ID=your_user_uuid   # optional, for local testing
```

Start the server:

```bash
python api.py
```

### 3. Client setup

```bash
cd client
npm install
```

Create a `.env` file in `/client`:

```env
EXPO_PUBLIC_SUPABASE_URL=your_supabase_url
EXPO_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
EXPO_PUBLIC_API_URL=http://localhost:5000
```

Start the app:

```bash
npx expo start
```

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/add-workout` | Log a new workout |
| GET | `/api/get-workouts` | Get all workout types + dates |
| GET | `/api/get-recent-exercises` | Last exercises for a workout type |
| GET | `/api/get-workout-details` | Full details for a specific date |
| GET | `/api/overall-stats` | All-time stats |
| GET | `/api/recent-stats` | Last 30 days stats |
| GET | `/api/get-exercise-stats` | Weight progression for an exercise |
| GET | `/api/get-tips` | AI-generated training tips |
| GET | `/api/get-chatbot-response` | AI coach response |
